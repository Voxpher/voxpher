How it started

From curiosity to production.

Web experiments came first — WordPress, WooCommerce, PHP and MySQL — learning how the internet actually serves things. Then the real engineering: JavaScript deeply, then Flutter and Dart for mobile, Node.js and Express for backends, MongoDB for data, Firebase for auth and services, Google Maps for location.

The result: I can take a product from a sketch to a Play Store listing backed by a live API — alone. Indoride is the proof.
